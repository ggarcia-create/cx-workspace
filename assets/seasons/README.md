# Decoraciones de temporada · v0.7.1

Ilustraciones creadas con la herramienta integrada image_gen, usando las tres capturas aportadas por el usuario como referencias de estilo. Los atlas transparentes se muestran por celdas con CSS, conservando la aplicación como interfaz interactiva.

Prompt común: «Create production decoration SPRITE ATLAS ONLY, no UI, no text. Reference supplied is style reference; closely reproduce decoration artwork detail and colors. Canvas 1536x1024, EXACT 3 columns by 2 rows of six equal 512x512 cells, each separate object centered and entirely contained inside its cell with 16px transparent padding. Genuine transparent background throughout. No labels no gridlines.»

- muertos.png: calavera con cempasúchil, hojas moradas y vela; papel picado naranja, rosa y morado; flor; conjunto floral con calavera; calavera individual; pétalos y hojas.
- halloween.png: árbol, casa embrujada y calabazas; telaraña con araña; murciélago; cementerio con árbol y calabazas; franja de pasto con tumbas; pareja de murciélagos.
- christmas.png: regalos, ramas de pino y esferas rojas; guirnalda con luces cálidas; copo dorado; ramas, esferas y piñas; piso de nieve; rama con bayas rojas.

Se conservan las fechas automáticas y la opción de desactivar las decoraciones en Configuración → Apariencia.
